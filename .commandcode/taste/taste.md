# Taste

## Communication
- Writes in casual Indonesian (informal "gue/bro" register) and expects replies in Indonesian at the same informal tone. Confidence: 0.65
- Dislikes being lectured / over-warned ("bawel"): wants the point stated once, briefly, then move on to the work rather than repeated cautionary explanations. Confidence: 0.8
- Expects the assistant to execute the requested task rather than second-guessing it or "holding" its own judgment — re-raises the same point after the user has already accepted the risk and it visibly irritates him. Confidence: 0.7

## Code organization
- Values maintainability and modularity above all: prefers code split into small, single-concern modules (orchestrator + focused helpers) over large multi-purpose files, and expects maintainability to be considered proactively when touching existing code. Confidence: 0.85
